# Electribe EA-1 Web Synth

A 16-step sequencer with dual synths, drums, and ambience powered by Web Audio + Pyodide.

## Prerequisites
- Node.js 18+

## Setup
```powershell
npm install
```

## Development
```powershell
npm run dev
```

## Testing
```powershell
npm test
```

## Build
```powershell
npm run build
```

## Preview Production Build
```powershell
npm run preview
```

## Deploy
```powershell
npm run deploy
```

## SVG Demo
```powershell
npm run demo
```
Or open `svg-demo.html` in your browser to see a pure SVG-based sequencer interface with interactive step buttons, knobs, and transport controls.
