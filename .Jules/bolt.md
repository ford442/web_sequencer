## 2026-05-15 - Shallow clone over deep cloning \n**Learning:** Deep cloning using `JSON.parse(JSON.stringify())` on hot paths causes immense garbage collection and layout calculations, especially in sequencer state updates. We must write custom update functions with spread clones.\n**Action:** Use object spread operator to shallow clone state for update paths and remove reactive dependencies from `useCallback` hooks using ref values (e.g. `activeSamplerBankRef.current`) inside `useAppState.tsx`.
