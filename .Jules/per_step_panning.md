## 2026-07-08 - Per-Step Panning
**Learning:** For parameters to correctly propagate through a decentralized audio orchestration architecture (like `createPlaySynth` or `createPlayDrum` or separated WebAudio context schedulers), updates to the common `Note` data structures must be explicitly mapped down to effective engine configuration objects (e.g., `effectiveParams` and `bankParams`). Furthermore, component context (such as the main properties `ContextMenuNode`) relies on being continuously passed these new properties via explicit prop drilling from the parent application state (`useAppState`).
**Action:** When adding new properties to the sequencing engines, trace the property down from the UI configuration structure (`types.ts`, `NoteSelector.tsx`, `ContextMenuNode.tsx`, `useAppState.ts`) all the way down to the individual hardware abstractions mapping (`audioPlayback.ts`, `useStepHandler.ts`) to ensure it actually routes to the native WebAudio panners (`createStereoPanner()` and `VoiceManager` `pan` bindings).
