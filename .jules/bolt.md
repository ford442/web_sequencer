## 2025-02-18 - AudioWorklet Loop Optimizations
**Learning:** In V8/JavaScript WebAudio AudioWorklets, hoisting constant logic out of per-sample DSP inner loops (like bitcrushing step calculations or constant multipliers) and explicitly unrolling dynamic channel loops (e.g. replacing `for (let channel=0;...){}` with `const out0 = outputs[0][0]; if (out0) { ... }`) significantly speeds up execution by eliminating loop branching, conditional checks, and O(N) array property lookups per quantum on the hot path. Converting divisions (`x / y`) to multiplications (`x * (1/y)`) by precalculating reciprocals provides a further consistent boost.
**Action:** When working in high-frequency audio DSP code, aggressively look for loop unswitching, branch hoisting, and constant expression precalculation. Exploit the fact that this app primarily handles stereo (2 channels maximum) to explicitly unroll loops targeting index 0 and index 1 instead of iterating arbitrarily.
