💡 What: Replaced \`dryBlock = new Float32Array(input)\` with direct loop indexing over the input array, replaced \`new Float32Array(length)\` in \`getAlignedDrySamples\` with a pre-allocated \`alignedDryScratch\` class property, and removed the \`pendingArtifacts.map()\`-equivalent array mapping block in \`sendPeriodicReport\` which now just passes the internal array and clears it with \`.length = 0\`.

🎯 Why: AudioWorklets process blocks of 128 samples at extremely high frequencies. Allocating multiple \`Float32Array\`s or new standard arrays per block pushes significant pressure onto the V8 garbage collector, causing audio thread stutters and potential dropouts.

📊 Impact: Eliminates ~3 arrays and closures created per audio block (every ~2.6ms) in the artifact detection path.

🔬 Measurement: Run \`pnpm run test:perf\` or monitor the Engine HUD (\`Ctrl+Shift+E\`) to observe fewer GC pauses during heavy pitch-shifting operations.
