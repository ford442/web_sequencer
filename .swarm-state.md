## Open303 — DONE
**Root cause:** `public/hyphon_wasm_export_map.json` was `{}`. Release `hyphon_native.wasm` exports are wasm-opt minified (`da`, `fa`, …); AudioWorklets instantiate WASM directly and could not resolve `open303_*` symbols → worklet init failed → `FallbackBassSynth`.

**Changes:**
- `tools/extract_wasm_export_map.mjs` — regex updated for current Emscripten glue (`Module["_foo"]=wasmExports["bar"]`)
- `public/hyphon_wasm_export_map.json` — regenerated (40–46 mappings)
- `src/utils/engineTelemetry.ts` — `parseHyphonGlueExportMap`, `loadHyphonWasmExportMap` (JSON → glue fallback)
- `src/engines/Open303Oscillator.ts` — uses `loadHyphonWasmExportMap`

**Tests:** `engineInitPaths.test.ts`, `Open303Config.test.ts` (export map mock), `hyphonNativeImports.test.ts`

---

## JC303 — DONE
**Root cause:** Same as Open303 (shared `hyphon_native.wasm` + `open303-processor` worklet). `set-engine` to `jc303` was a no-op because `jc303_*` exports were never resolved.

**Changes:** Export map fix above; no separate JC303 code path change required.

**Tests:** Covered by export-map + Open303 init tests.

## Rust — DONE (code fix; browser smoke recommended)
**Root cause classification:** Dynamic import of `rust-wasm/rust_audio.js` relied on `import.meta.url` inside wasm-bindgen glue to locate `rust_audio_bg.wasm`; explicit BASE_URL-resolved path is safer for subdirectory deploys. Test env cannot `import()` http URLs (classified, not a code bug).

**Changes:**
- `src/engines/RustOscillator.ts` — `mod.default(resolvePublicAsset('rust-wasm/rust_audio_bg.wasm'))`

**Tests:** `RustOscillator.test.ts`, `engineInitPaths.test.ts` (classified fallback)

## Pyodide — PARTIAL (async bootstrap)
**Root cause classification:** Pyodide loads after `hyphon_native.js` via `initPyodideSystem` (numpy/scipy CDN fetch). Before ready, `VoiceManager` correctly falls back with `logEngineFallback`; `useAudioEngine` updates deps when pyodide arrives.

**Changes:** User-visible warning path (shared telemetry). No Pyodide bootstrap code change — export map / native module load was the blocker for the C++ orchestrator chain.

**Tests:** `src/hooks/__tests__/usePyodideEngine.test.ts` (timeout + ready event)

**Precondition:** Network access for Pyodide packages; `hyphon_native.js` must load (COOP/COEP already in `vite.config.ts`).
